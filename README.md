# 🍦 CraveRush

> **Crave it! Match it! Love it!**

CraveRush is a **dessert & ice cream discovery and recommendation platform** that helps users find, compare, and discover desserts based on taste, calories, alternatives, and available partner stores.

## ✨ Features

- 🔍 Search across 141 products
- ⚖️ Compare multiple products
- 💡 Product alternatives
- 📍 Partner-store availability
- 🔥 Calorie information
- 🛒 Saved List
- 👤 Multi-user accounts
- 🌙 Dark Mode
- 📱 Responsive design

## 🧁 Categories

**Cakes · Pastries · Pancakes · Waffles · Indian Sweets · Donuts · Cookies & Brownies · Ice Creams**

## 🛠️ Tech Stack

**HTML5 · CSS3 · Bootstrap 5.3 · Vanilla JavaScript · Owl Carousel 2 · localStorage**

## 🎯 Project Type

**Frontend-only recommendation platform**

No backend, ordering, checkout, payment, or delivery system.
