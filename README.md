# 🍦 CraveRush

> **Crave it! Match it! Love it!**

CraveRush is a dessert and ice cream discovery and recommendation platform designed to help users explore, compare, and discover desserts based on taste, calorie information, alternatives, and available partner stores.

The project focuses on creating an engaging and user-friendly frontend experience for dessert lovers, combining product discovery, comparison features, and personalized selections within a single platform.

## ✨ Features

- 🔍 **Product Search** — Search across 141 dessert and ice cream products.
- ⚖️ **Product Comparison** — Compare multiple products.
- 💡 **Product Alternatives** — Discover alternative products.
- 📍 **Partner Store Availability** — Explore available partner-store information.
- 🔥 **Calorie Information** — View calorie details for products.
- 🛒 **Saved List** — Save products for later.
- 👤 **Multi-User Accounts** — Frontend user account interface.
- 🌙 **Dark Mode** — Switch between light and dark themes.
- 📱 **Responsive Design** — Adaptable interface across different screen sizes.

## 🧁 Categories

Cakes · Pastries · Pancakes · Waffles · Indian Sweets · Donuts · Cookies & Brownies · Ice Creams

## 🛠️ Tech Stack

HTML5 · CSS3 · Bootstrap 5.3 · Vanilla JavaScript · Owl Carousel 2 · localStorage

## 🎯 Project Type

**Frontend-only Dessert Discovery & Recommendation Platform**

The project focuses exclusively on frontend functionality and user interface interactions. It does not include a backend, online ordering, checkout, payment processing, or delivery system.
